## Notes importantes

- **Redémarrage service après changement de code** : tout changement de code nécessite `./deploy/deploy.sh` (git pull + uv sync + `systemctl restart cineorg.service`) pour être pris en compte par le service systemd — piège identifié dans la session précédente (bug réassociation/collection). Pour tester en local, `uv run uvicorn src.web.app:app --reload` suffit mais le service systemd ne reflète pas les modifs tant qu'il n'est pas redémarré.
- **Tests** : `uv run pytest` direct ne fonctionne pas (pytest pas dans les deps principales). Utiliser `uv run --with pytest --with respx python -m pytest ...` ou `uv sync --all-extras` une fois puis `uv run python -m pytest ...`.
