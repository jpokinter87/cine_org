<objective>
## Goal
Permettre à l'utilisateur de compléter/corriger manuellement les fiches films et
séries depuis l'interface web (affiche, synopsis, casting) et protéger ces
modifications de l'écrasement par l'enricher automatique.

## Purpose
Combler les rares cas où TMDB/TVDB n'ont pas de jaquette, pas de synopsis, ou
un casting incomplet — sans passer par l'édition DB manuelle. Assurer qu'une
donnée saisie par l'utilisateur ne disparaisse jamais silencieusement lors
d'un re-enrichissement.

## Output
- Nouvelles colonnes `*_override` sur `MovieModel` et `SeriesModel` (poster,
  overview, cast) + flag `preserve_overrides` par entité.
- Répertoire `storage/.metadata/posters/` pour les affiches uploadées.
- Service `metadata_overrides.py` : helpers d'upload + chemins.
- Bouton « Éditer » sur les fiches web + overlay HTMX d'édition (upload
  affiche OU URL externe, textarea synopsis, liste nom+rôle pour casting).
- Affichage fiches : priorité à l'override (`effective_poster/overview/cast`)
  avec badge discret « modifié manuellement ».
- Enricher + reassociate respectent `preserve_overrides=True` (skip
  entité).
- Suite de tests pour les trois volets.
</objective>
