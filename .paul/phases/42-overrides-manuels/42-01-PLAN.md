<objective>
## Goal
Détecter automatiquement, à l'issue du workflow, les groupes (série, saison) dont des épisodes ont été rejetés parce que leur numéro dépasse le canon TVDB. Les présenter **dans le résumé de fin de workflow** (`workflow/_results.html`, à côté des stats scanned/auto-validé/pending), où l'utilisateur peut, d'un seul clic, accepter tout le groupe comme « découpage alternatif » — action qui crée un override persistant, valide les pendings du groupe et marque les épisodes `is_extra=True`.

## Purpose
Débloquer le cas *The Big C* S04 (4 épisodes TVDB vs 8 locaux) et tous les cas similaires, sans action fichier-par-fichier ni pré-configuration. Le programme détecte le pattern et propose la résolution. Le signal « X saisons déjà validées » donne confiance qu'il s'agit bien de la même série.

## Output
- Table `season_overrides` + colonne `episodes.is_extra`.
- Les deux filtres d'épisodes (matching + auto-validation) consultent l'override avant de rejeter.
- Section « Cas particuliers à traiter » dans `workflow/_results.html`, listant les groupes `(série TVDB, saison)` avec épisodes en excès.
- Action groupée « Accepter N épisodes comme découpage alternatif » → override + validations + `is_extra=True`.
- Pas de nouvelle page : la résolution se fait sur la page workflow, aux côtés du résumé chiffré.
</objective>

    **3a. Service de détection (nouveau fichier)**

    Créer `src/services/anomaly_detector.py` avec une classe
    `AnomalyDetector` :

    ```python
    @dataclass
    class ExcessEpisodeGroup:
        tvdb_id: int
        series_title: str
        series_year: int | None
        season_number: int
        tvdb_count: int
        pendings: list[PendingValidationModel]  # triés par episode_number
        validated_seasons_count: int  # nb saisons distinctes déjà en DB

    class AnomalyDetector:
        def __init__(self, session, tvdb_client, series_repo):
            ...

        async def find_excess_episode_groups(self) -> list[ExcessEpisodeGroup]:
            """Groupe les pendings par (tvdb_id, season) où episode > canon."""
    ```

    Algorithme :
    1. Lister les `PendingValidationModel` en statut PENDING.
    2. Pour chacun, parser `(season, episode)` depuis le filename
       via `_extract_series_info()` (helper existant).
    3. Sélectionner le **top candidat TVDB** parmi `pending.candidates`
       (source=="tvdb", score max).
    4. Grouper par `(tvdb_id du top candidat, season)`.
    5. Pour chaque groupe, appeler `tvdb_client.get_season_episode_count(tvdb_id, season)`.
    6. Filtrer : ne garder que les groupes où **au moins un pending a
       `episode_number > tvdb_count`**, et ne conserver dans
       `pendings` que ceux-là.
    7. Pour chaque groupe, compter les saisons distinctes déjà
       présentes dans `episodes` pour `series.tvdb_id == tvdb_id`
       (requête GROUP BY `season_number`) → `validated_seasons_count`.

    Cache léger dans la méthode (pour éviter appels TVDB redondants
    quand plusieurs groupes partagent le même tvdb_id — peu probable
    mais pas coûteux).

    Tests `tests/unit/test_anomaly_detector.py` :
