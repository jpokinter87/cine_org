<objective>
## Goal
Réorganiser les 14 contrôles de filtres de la page Bibliothèque en groupes logiques avec un design épuré, et remplacer le select Croissant/Décroissant par des flèches directionnelles intégrées au cartouche Tri.

## Purpose
L'interface actuelle est trop chargée visuellement : 14 contrôles en une seule rangée, l'utilisateur ne distingue pas les filtres principaux des filtres techniques. La refonte améliore l'ergonomie et la lisibilité sans changer les fonctionnalités.

## Output
- Template `_filters.html` restructuré en 3 zones : filtres principaux (recherche, type, genre, année, tri+flèches), filtres techniques (collapsible : résolution, codecs vidéo/audio, langue), filtres spéciaux (checkboxes non-vus, sans fichier, sans poster)
- CSS mis à jour pour le nouveau layout et les flèches de tri
- Suppression du select `order` (Croissant/Décroissant) remplacé par boutons flèche ↑↓
</objective>

    5. Conserver intégralement la section `lib-active-filters` (tags) et les inputs hidden (person, person_role)
    6. Conserver la construction de `base_params` pour la pagination

    2. `.lib-filters-main` : flex row, wrap, gap
    3. `.lib-sort-group` : display flex, no gap, les boutons flèche collés au select
       - `.lib-sort-arrow` : bouton carré, fond card, bordure, icône SVG flèche
       - `.lib-sort-arrow.active` : couleur ambrée, fond amber-dim
       - Le select perd son border-radius droit, le dernier bouton a le border-radius droit
    4. `.lib-filters-tech` : wrapper avec transition max-height pour animation
       - `.lib-tech-toggle` : bouton stylé comme un label, chevron rotatif
       - `.lib-tech-content` : overflow hidden, max-height 0 par défaut, transition
       - `.lib-filters-tech.open .lib-tech-content` : max-height suffisant, margin-top
       - `.lib-filters-tech.open .lib-tech-toggle` : chevron tourné
    5. `.lib-filters-special` : flex row, gap, margin-top léger
    6. Adapter le responsive (max-width: 768px) pour le nouveau layout
    7. Conserver les styles existants qui sont encore utilisés (.lib-filter-select, .lib-search-wrap, etc.)
    8. Supprimer les styles orphelins (.lib-filter-order)
