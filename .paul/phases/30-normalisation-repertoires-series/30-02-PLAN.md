    **B) Créer la commande `migrate-series` :**

    Créer `src/adapters/cli/commands/migrate_series_command.py` avec :

    ```python
    @app.command("migrate-series")
    def migrate_series(
        dry_run: bool = Option(True, help="Afficher le plan sans exécuter"),
        reclassify: bool = Option(False, help="Reclassifier animation/mangas/documentaires"),
    ):
    ```

    **Étapes de la commande :**

    1. **Scan** : détecter les répertoires à renommer
       - `storage_dir / "Séries"` → `storage_dir / "Series"`
       - `storage_dir / "Series" / "Séries TV"` → `storage_dir / "Series" / "TV"` (ou `storage_dir / "Séries" / "Séries TV"` si pas encore renommé)
       - Idem dans `video_dir`

    2. **Plan DB** : compter les file_path à mettre à jour
       - `episodes.file_path LIKE '%/Séries/%'`
       - `video_files.path LIKE '%/Séries/%'`
       - `video_files.symlink_path LIKE '%/Séries/%'`
       - Aussi : remplacements `Séries TV` → `TV`

    3. **Plan symlinks** : lister les symlinks qui casseront après renommage des dirs storage

    4. **Si --reclassify** : interroger la DB pour les séries avec genre Animation/Anime/Documentaire
       - Joindre series (genres_json) → episodes (file_path) → identifier les fichiers à déplacer
       - Calculer les nouveaux chemins via `get_series_video_destination()` / `get_series_destination()`

    5. **Affichage dry-run** : table Rich avec toutes les opérations planifiées (renommages dirs, updates DB, reclassifications)

    6. **Exécution** (si `--no-dry-run`) :
       a. Renommer les répertoires physiques (storage puis video) avec `Path.rename()`
       b. SQL bulk updates sur DB (ordre : plus spécifique d'abord) :
          ```sql
          -- Sous-répertoire d'abord
          UPDATE episodes SET file_path = REPLACE(file_path, '/Séries TV/', '/TV/') WHERE file_path LIKE '%/Séries TV/%';
          UPDATE episodes SET file_path = REPLACE(file_path, '/Séries/', '/Series/') WHERE file_path LIKE '%/Séries/%';
          -- Idem pour video_files.path et video_files.symlink_path
          ```
       c. Recréer les symlinks cassés dans video/ (itérer, lire la cible, si cassé recréer vers le nouveau chemin)
       d. Si --reclassify : déplacer les fichiers et mettre à jour DB/symlinks

    **Enregistrer dans src/main.py** : ajouter `app.command()(migrate_series)`

    **IMPORTANT :**
    - Utiliser `shutil.move()` au lieu de `Path.rename()` si cross-device (NAS)
    - Ordre des renames : renommer les sous-dirs AVANT les dirs parents
    - Confirmer avec l'utilisateur avant exécution (Prompt.ask)
    - Afficher un résumé final avec compteurs
