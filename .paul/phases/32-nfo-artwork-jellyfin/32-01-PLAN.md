<objective>
## Goal
Générer des fichiers NFO (XML Kodi/Jellyfin) et télécharger les artworks (poster.jpg, fanart.jpg) pour les films et séries, placés dans video/ à côté des symlinks. Jellyfin lira directement ces métadonnées sans requêter d'API externe.

## Purpose
Jellyfin est installé et configuré avec les bibliothèques Films et Séries via symlinks CineOrg. Sans NFO/artwork sidecar, Jellyfin doit scraper TMDB/TVDB lui-même, ce qui peut donner des résultats incorrects. En générant les NFO depuis les données validées de CineOrg, on garantit la cohérence entre CineOrg et Jellyfin.

## Output
- Service `NfoGeneratorService` générant les XML NFO et téléchargeant les images
- Commande CLI `generate-nfo` avec options --type (movies/series/all), --force, progression Rich
- Fichiers NFO/artwork placés dans video/ à côté des symlinks existants
</objective>

    - `generate_series_nfo(force=False, progress_callback=None) -> NfoResult` — itère les séries, génère tvshow.nfo + épisodes + artwork

    - `_build_movie_xml(movie: MovieModel) -> str` — construit le XML NFO film
    - `_build_tvshow_xml(series: SeriesModel) -> str` — construit le XML NFO série
    - `_build_episode_xml(episode: EpisodeModel) -> str` — construit le XML épisode

    **Format XML NFO film (Kodi/Jellyfin compatible) :**
    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <movie>
      <title>{title}</title>
      <originaltitle>{original_title}</originaltitle>
      <year>{year}</year>
      <plot>{overview}</plot>
      <runtime>{duration_seconds // 60}</runtime>
      <genre>{genre1}</genre>
      <genre>{genre2}</genre>
      <director>{director}</director>
      <actor><name>{actor}</name></actor>
      <rating>{vote_average}</rating>
      <uniqueid type="tmdb" default="true">{tmdb_id}</uniqueid>
      <uniqueid type="imdb">{imdb_id}</uniqueid>
      <thumb aspect="poster">poster.jpg</thumb>
      <fanart><thumb>fanart.jpg</thumb></fanart>
    </movie>
    ```

    **Format XML NFO série :**
    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <tvshow>
      <title>{title}</title>
      <originaltitle>{original_title}</originaltitle>
      <year>{year}</year>
      <plot>{overview}</plot>
      <genre>{genre}</genre>
      <uniqueid type="tvdb" default="true">{tvdb_id}</uniqueid>
      <uniqueid type="tmdb">{tmdb_id}</uniqueid>
      <uniqueid type="imdb">{imdb_id}</uniqueid>
      <rating>{vote_average}</rating>
      <thumb aspect="poster">poster.jpg</thumb>
    </tvshow>
    ```

    **Format XML NFO épisode :**
    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <episodedetails>
      <title>{title}</title>
      <season>{season_number}</season>
      <episode>{episode_number}</episode>
      <plot>{overview}</plot>
      <aired>{air_date}</aired>
    </episodedetails>
    ```

    **Localisation des fichiers dans video/ :**
    - Film : le symlink est `video/Films/.../Film Name (Year) ...ext`. Le NFO = même chemin avec `.nfo` au lieu de l'extension vidéo. Le poster.jpg et fanart.jpg vont dans le même dossier.
    - Série : le dossier racine = `video/Series/.../Series Name (Year)/`. Placer tvshow.nfo + poster.jpg ici.
    - Épisode : le symlink est `video/Series/.../Series Name (Year)/Saison XX/episode.ext`. Le NFO = même chemin avec `.nfo`.

    **Trouver les chemins video/ depuis file_path (storage/) :**
    - Pour les films : le file_path est dans storage/. Le symlink correspondant dans video/ pointe vers ce fichier. Chercher le symlink existant dans video/ dont la cible résout vers le file_path du film. Utiliser `Path.rglob()` serait trop lent. Alternative plus efficace : construire le chemin video/ à partir de la structure connue : `video/Films/` miroir de `storage/Films/`. Remplacer le préfixe storage_dir par video_dir dans le file_path.
    - Pour les séries : même logique avec `storage/Series/` → `video/Series/`.

    **Téléchargement d'images :**
    - Utiliser httpx (déjà dans les dépendances) pour télécharger les images TMDB
    - Poster : `https://image.tmdb.org/t/p/w500{poster_path}` → `poster.jpg`
    - Fanart : `https://image.tmdb.org/t/p/w1280{backdrop_path}` → `fanart.jpg`
    - Pour le backdrop_path (non stocké en DB) : appeler `tmdb_client.get_details()` pendant la génération et extraire backdrop_path de la réponse API. Modifier TMDBClient._parse_details() pour aussi retourner backdrop_path via un champ supplémentaire dans MediaDetails.
    - Rate limiting : respecter un délai entre les requêtes image (0.25s) pour ne pas surcharger TMDB

    **Ajouter `backdrop_path` à MediaDetails :**
    - Dans `src/core/ports/api_clients.py`, ajouter `backdrop_url: Optional[str] = None` à MediaDetails
    - Dans `src/adapters/api/tmdb_client.py`, extraire `backdrop_path` de la réponse API et construire l'URL complète
