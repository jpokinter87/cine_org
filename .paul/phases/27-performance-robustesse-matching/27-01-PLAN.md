## AC-1: Cache TVDB bulk par saison
```gherkin
Given une série avec 24 épisodes dans la saison 1
When get_episode_details est appelé pour chaque épisode
Then la première requête fait un appel bulk à l'API TVDB pour toute la saison
And les 23 appels suivants sont servis depuis le cache local
And le nombre total de requêtes HTTP vers TVDB est de 1 (au lieu de 24)
```

## AC-2: Compteurs workflow cohérents
```gherkin
Given un workflow web terminé avec N fichiers scannés
When les résultats finaux sont affichés
Then scanned = nombre réel de PendingValidation créées en DB
And auto_validated + pending_remaining = scanned
And aucun décalage entre compteurs affichés et état en base
```

## AC-3: Parsing et renommage VOSTFR
```gherkin
Given un fichier nommé "MonFilm.VOSTFR.1080p.BluRay.mkv"
When guessit parse le nom du fichier
Then ParsedFilename.subtitle_language = "fr"
And le renommage inclut "VOSTFR" dans le suffixe technique
```

## AC-4: Compatibilité MULTI existante
```gherkin
Given un fichier nommé "MonFilm.MULTI.1080p.mkv"
When guessit parse le nom du fichier
Then ParsedFilename.language contient "Multi"
And le renommage affiche "Multi" (pas "MUL")
```

    **Ajouter une méthode de fetch bulk par saison dans TVDBClient :**

       - Vérifie d'abord si une clé `tvdb:season_bulk:{series_id}:S{season:02d}` existe dans le cache
       - Si non, appelle `/series/{series_id}/episodes/query?airedSeason={season}` (toutes les pages)

    3. Modifier `get_season_episode_count(series_id, season)` pour utiliser `_fetch_season_episodes` si pas en cache, ainsi le count ET les épisodes sont cachés en une seule requête.
