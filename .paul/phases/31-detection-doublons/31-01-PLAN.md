<objective>
## Goal
Créer la commande CLI `check-duplicates` qui détecte les films ayant le même `tmdb_id` dans la base, compare leur qualité via le `QualityScorerService` existant, et recommande quelle version garder. Inclure un mécanisme de whitelist pour les doublons volontaires.

## Purpose
Plusieurs films peuvent exister en double dans la vidéothèque (re-téléchargement en meilleure qualité, versions différentes). La détection permet d'identifier ces doublons, comparer objectivement leur qualité, et guider le nettoyage.

## Output
- Commande CLI `check-duplicates` avec mode dry-run
- Whitelist JSON pour doublons volontaires
- Tests unitaires
</objective>

<task type="auto">
  <name>Task 1: Commande check-duplicates</name>
  <files>src/adapters/cli/commands/duplicates_command.py, src/adapters/cli/commands/__init__.py, src/main.py</files>
  <action>
    Créer la commande `check-duplicates` :

    1. **Détection** via requête SQL directe :
       ```sql
       SELECT tmdb_id, COUNT(*) as cnt, GROUP_CONCAT(id) as ids
       FROM movies
       WHERE tmdb_id IS NOT NULL AND file_path IS NOT NULL
       GROUP BY tmdb_id
       HAVING COUNT(*) > 1
       ```

    2. **Scoring** : pour chaque film du groupe, reconstruire un `MediaInfo` depuis les champs `MovieModel` (resolution string "WxH" → Resolution, codec_video → VideoCodec, codec_audio → AudioCodec) et appeler `calculate_quality_score()`.

    3. **Whitelist** : charger `config/duplicates_whitelist.json` (liste de tmdb_id). Les groupes whitelistés sont affichés séparément. Format : `{"whitelist": [12345, 67890], "notes": {"12345": "Version longue + version cinéma"}}`.

    4. **Affichage Rich** :
       - Table par groupe : titre, année, poster absent
       - Par copie : file_path (nom court), résolution, codec, langues, taille, score qualité
       - Indicateur ★ sur la meilleure version
       - Résumé : N groupes de doublons, N fichiers, taille récupérable
       - Section séparée pour les whitelistés

    5. **Options CLI** :
       - `--dry-run/--no-dry-run` (défaut: dry-run, mais ici c'est toujours informatif — pas d'action destructive)
       - `--verbose/-v` : affiche le détail des scores par critère
       - `--whitelist-add TMDB_ID` : ajoute un tmdb_id à la whitelist
       - `--whitelist-remove TMDB_ID` : retire un tmdb_id de la whitelist

    Pattern CLI : fonction sync, Rich console/Table/Panel, suppress_loguru, Progress spinner.
    Réutiliser `calculate_quality_score` du module existant (import direct, pas besoin du service DI).

    Enregistrer dans __init__.py et main.py.
  </action>
  <verify>uv run python -m src.main check-duplicates --help</verify>
  <done>AC-1, AC-2, AC-3, AC-4 satisfaits : commande fonctionnelle avec détection, scoring, whitelist et affichage</done>
</task>

       - 3 films même tmdb_id → 1 groupe de 3

       - Film 1080p x265 > Film 720p x264 → Film 1 recommandé

    3. **Whitelist** :

    4. **Reconstruction MediaInfo** depuis les champs MovieModel :
       - Resolution "1920x1080" → Resolution(1920, 1080)
       - Resolution None ou vide → None
       - Codec "x265" → VideoCodec(name="x265")
