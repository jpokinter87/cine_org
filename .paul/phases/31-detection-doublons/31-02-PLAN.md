<objective>
## Goal
Créer une page web "/duplicates" qui affiche les groupes de doublons détectés (même tmdb_id), compare visuellement la qualité de chaque copie, et permet d'ajouter/retirer des tmdb_id de la whitelist directement depuis l'interface.

## Purpose
L'utilisateur doit pouvoir visualiser et gérer les doublons depuis le navigateur, avec posters, scores, et actions rapides — complément visuel de la commande CLI `check-duplicates`.

## Output
- Route FastAPI `/duplicates` avec rendu Jinja2
- Template avec affichage par groupe (poster + copies comparées)
- Actions HTMX : whitelist add/remove
</objective>

<task type="auto">
  <name>Task 1: Route et templates doublons</name>
  <files>src/web/routes/duplicates.py, src/web/templates/duplicates/index.html, src/web/templates/duplicates/_results.html, src/web/app.py</files>
  <action>
    1. **Route `/duplicates`** (GET) dans `src/web/routes/duplicates.py` :
       - `APIRouter(prefix="/duplicates")`
       - Requête SQL directe : GROUP BY tmdb_id HAVING COUNT > 1 (même logique que CLI)
       - Pour chaque groupe : charger les films, reconstruire MediaInfo, calculer le score
       - Séparer doublons vs whitelistés (charger config/duplicates_whitelist.json)
       - Pas de SSE nécessaire — la requête est rapide (pas de scan filesystem)
       - Rendu synchrone via `templates.TemplateResponse`

    2. **Route `/duplicates/whitelist-add` (POST)** :
       - Reçoit tmdb_id en form data
       - Ajoute à la whitelist JSON
       - Retourne un fragment HTMX (rechargement partiel)

    3. **Route `/duplicates/whitelist-remove` (POST)** :
       - Reçoit tmdb_id en form data
       - Retire de la whitelist JSON
       - Retourne un fragment HTMX

    4. **Template `index.html`** :
       - Extends base.html
       - Section doublons à traiter : cartes par groupe
       - Chaque carte : poster à gauche, table des copies à droite
       - Indicateur ★ ou badge "Meilleure" sur la version au score le plus élevé
       - Bouton "Accepter" (hx-post whitelist-add)
       - Section doublons acceptés en bas (collapsible)
       - Résumé en haut : N groupes, N fichiers, taille récupérable

    5. **Template `_results.html`** (partial) :
       - Fragment rechargé après action whitelist (HTMX swap)

    6. **Montage dans app.py** :
       - Import et include_router du nouveau router

    Réutiliser les fonctions utilitaires du CLI : `_build_media_info`, `_format_size`, `_format_resolution`, `_format_languages`, `_load_whitelist`, `_save_whitelist`.
    Les importer directement depuis `src.adapters.cli.commands.duplicates_command`.
  </action>
  <verify>uv run uvicorn src.web.app:app --host 0.0.0.0 --port 8000 — visiter /duplicates</verify>
  <done>AC-1, AC-2, AC-3, AC-4 satisfaits</done>
