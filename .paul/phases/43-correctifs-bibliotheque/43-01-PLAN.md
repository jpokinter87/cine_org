<objective>
## Goal
Rendre la recherche bibliothèque insensible aux accents, dans les deux sens :
« Millenium » trouve « Millénium » et inversement. Couvre tous les caractères
diacritiques latins (é/è/ê/à/â/ç/ô/û/ñ/…), pas uniquement ceux du français.

## Purpose
Lever un irritant utilisateur quotidien : l'utilisateur ne sait pas toujours
si la fiche TMDB porte l'accent (« Millénium » série vs « Millenium » saga
américaine), et taper avec/sans accent donne aujourd'hui des résultats
partiels et incohérents.

## Output
- UDF SQLite `unaccent(text)` enregistrée automatiquement sur chaque
  connexion de l'engine via le listener SQLAlchemy `connect`.
- Helper `strip_accents(text)` déjà disponible (`normalize_accents` dans
  `src/utils/helpers.py`) exposé comme UDF.
- `_title_search_filter` utilise `unaccent(title)` LIKE `unaccent(query)`
  côté SQL, en plus du LIKE direct (pour garder le fallback ligatures).
- Variantes `search_variants` étendues avec la version accent-stripped (pour
  que les ligatures ET les accents soient couverts par le même mécanisme).
- Tests unitaires dédiés couvrant 4 cas : accent→sans, sans→accent,
  ligatures, accents + ligatures simultanés.
</objective>

    **1a. Enregistrement UDF (`database.py`) :**

    Ajouter un listener SQLAlchemy `event.listens_for(Engine, "connect")`
    qui crée la fonction `unaccent(text)` sur chaque connexion DBAPI :

    ```python
    from sqlalchemy import event
    from sqlalchemy.engine import Engine

    @event.listens_for(Engine, "connect")
    def _register_sqlite_udfs(dbapi_connection, connection_record):
        # N'inscrire l'UDF que sur SQLite (test isinstance sqlite3.Connection)
        import sqlite3
        if isinstance(dbapi_connection, sqlite3.Connection):
            from src.utils.helpers import normalize_accents
            # deterministic=True permet l'utilisation dans les index et le
            # cache de requête.
            dbapi_connection.create_function(
                "unaccent", 1, normalize_accents, deterministic=True
            )
    ```

    Placer ce hook en haut de `database.py` (module-level) pour qu'il soit
    enregistré dès l'import. Le listener est global Engine — une seule
    inscription même avec plusieurs instances d'engine.

    Attention : `deterministic=True` requiert Python 3.8+ (déjà le cas).
    Si la version de SQLite embarquée est trop ancienne (avant 3.8.3),
    fallback sans le flag. Tester.

    **1b. Étendre search_variants (`src/utils/helpers.py`) :**

    Ajouter dans la liste des variantes la version accent-stripped de
    la query, en plus des formes existantes :
    ```python
    variants.update({normalize_accents(v) for v in variants})
    ```

    Cela permet le cas « l'utilisateur tape déjà sans accent mais la
    DB stocke avec accent » via les variantes, en complément de l'UDF
    côté SQL.

    **1c. Réécrire `_title_search_filter` (`src/web/routes/library/helpers.py`) :**

    Utiliser une condition SQL qui compare `unaccent(title)` à
    `unaccent(variant)` pour chaque variante :

    ```python
    from sqlalchemy import func, or_

    def _title_search_filter(model_class, q: str, extended: bool = False):
        variants = search_variants(q)
        # Comparaison avec UDF unaccent(), insensible aux accents
        title_conditions = [
            func.unaccent(model_class.title).like(f"%{func.unaccent(v).op('||')(' ')}%")
            for v in variants
        ]
        # ... (adapter au pattern LIKE existant)
    ```

    **Note sur l'opérateur LIKE** : SQLAlchemy `column.contains(v)` génère
    `column LIKE '%v%'`. Pour appliquer `unaccent` des deux côtés, on
    utilise `func.unaccent(column).like(f"%{unaccent_py(v)}%")` — le
    côté droit est pré-traité en Python via `normalize_accents(v)` pour
    éviter un surcoût SQL sur chaque ligne du côté droit.

    Algo final :
    ```python
    from src.utils.helpers import normalize_accents

    def _title_search_filter(model_class, q: str, extended: bool = False):
        variants = search_variants(q)
        conds = []
        for v in variants:
            conds.append(model_class.title.contains(v))
            # Version unaccent : compare titres DB dépouillés à query dépouillée
            unaccent_v = normalize_accents(v)
            conds.append(
                func.unaccent(model_class.title).like(f"%{unaccent_v}%")
            )
            if extended and hasattr(model_class, "overview"):
                conds.append(model_class.overview.contains(v))
                conds.append(
                    func.unaccent(model_class.overview).like(f"%{unaccent_v}%")
                )
        return or_(*conds)
    ```
