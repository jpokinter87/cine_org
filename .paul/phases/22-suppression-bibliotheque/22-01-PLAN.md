<objective>
## Goal
Implémenter la suppression par lot depuis la bibliothèque : filtrage multicritères enrichi, sélection par cases à cocher sur les jaquettes, corbeille provisoire réversible, et page corbeille (restauration, vidage définitif).

## Purpose
Permettre à l'utilisateur de nettoyer sa vidéothèque en sélectionnant visuellement les fiches à supprimer selon des critères combinés (ex: films SD en VOSTFR), avec un filet de sécurité via la corbeille avant suppression physique.

## Output
- TrashRepository pour CRUD sur TrashModel existant
- Filtres enrichis sur la page bibliothèque (langue, sans fichier, sans poster)
- Mode sélection avec cases à cocher sur les jaquettes
- Suppression par lot → corbeille (symlinks supprimés, storage conservé)
- Cascade série : supprimer une série supprime aussi ses épisodes
- Page corbeille : consultation, restauration individuelle, vidage définitif (suppression physique)
</objective>

<acceptance_criteria>

## AC-1: Filtres enrichis sur la bibliothèque
```gherkin
Given la page bibliothèque avec les filtres existants
When l'utilisateur sélectionne un filtre langue (ex: "en" pour VOSTFR)
Then seuls les films/séries avec cette langue s'affichent
And les filtres "sans fichier" et "sans poster" sont également disponibles
```

## AC-2: Mode sélection avec cases à cocher
```gherkin
Given la page bibliothèque avec des résultats affichés
When l'utilisateur active le mode sélection (bouton "Sélectionner pour suppression")
Then chaque jaquette affiche une case à cocher
And l'utilisateur peut cocher/décocher individuellement
And un compteur flottant affiche le nombre d'éléments sélectionnés
And un clic sur la jaquette ouvre toujours la fiche détail (pour vérification)
```

## AC-3: Suppression par lot vers corbeille
```gherkin
Given N éléments cochés dans le mode sélection
When l'utilisateur clique "Supprimer la sélection" et confirme via le dialogue
Then tous les éléments sélectionnés sont déplacés en corbeille
And les symlinks video/ sont supprimés
And les fichiers storage/ ne sont PAS supprimés
And pour les séries : les épisodes sont inclus dans la cascade
And l'utilisateur est redirigé vers la bibliothèque
```

## AC-4: Page corbeille (consultation, restauration, vidage)
```gherkin
Given des éléments dans la corbeille
When l'utilisateur visite la page corbeille (/library/trash)
Then il voit la liste des éléments supprimés (type, titre, date de suppression)
And il peut restaurer un élément individuellement (retour en bibliothèque + re-création symlink)
And il peut vider définitivement la corbeille (suppression physique storage/)
And le vidage requiert une confirmation
```

    2. **Filtres enrichis** dans browse.py — ajouter 3 paramètres au GET /library/ :
       - `language: Optional[str]` — filtre sur languages_json.contains(language)
       - `no_file: Optional[str]` — `== "1"` → where file_path IS NULL
       - `no_poster: Optional[str]` — `== "1"` → where poster_path IS NULL
       - Appliquer aux deux requêtes (films ET séries)
       - Passer les valeurs au template pour pré-remplir les filtres

    3. **Route POST /library/delete-batch** (nouveau fichier delete.py) :
       - Reçoit une liste d'IDs avec types : `items` = JSON array [{type: "movie", id: 42}, ...]
       - Pour chaque élément :
         * Charger le Model (MovieModel ou SeriesModel)
         * Sérialiser toutes les colonnes en metadata_json
         * Créer TrashModel(entity_type=type, original_id=id, metadata_json=JSON)
         * Supprimer le symlink video/ si VideoFileModel associé (via file_path → VideoFileModel → symlink_path)
         * Supprimer le VideoFileModel associé
         * Supprimer le Model de la DB
         * Pour les séries : cascade — récupérer tous les EpisodeModel, même traitement pour chaque épisode
       - Retourne JSON {deleted: N} + HX-Redirect vers /library/

    4. **Module trash.py** (nouveau) :
       - GET /library/trash — liste TrashModel, désérialise metadata_json pour afficher titre/type/date
       - POST /library/trash/{id}/restore :
         * Désérialiser metadata_json
         * Re-créer le MovieModel/SeriesModel/EpisodeModel + VideoFileModel
         * Re-créer le symlink si fichier storage/ existe encore (via OrganizerService + file_system)
         * Supprimer le TrashModel
         * Pour les séries : restaurer aussi les épisodes liés (même deletion_reason ou series_id stocké dans metadata)
       - POST /library/trash/empty :
         * Pour chaque TrashModel : supprimer le fichier storage/ physique (file_system.delete)
         * Supprimer tous les TrashModel
         * HX-Redirect vers /library/trash

    5. **Enregistrer les routers** dans library/__init__.py :
       - `from . import delete, trash`
       - `router.include_router(delete.router)`
       - `router.include_router(trash.router)`

    ATTENTION :
    - Ne PAS supprimer le fichier storage/ lors de la mise en corbeille (seulement au vidage)
    - Sérialiser TOUTES les colonnes du model pour restauration fidèle (y compris file_path, tmdb_id, etc.)
    - Pour cascade séries : stocker series_original_id dans metadata_json de chaque épisode trash
    - Utiliser request.app.state.container pour accéder au file_system (DI)
