<objective>
## Goal
Résoudre les 383 épisodes sans titre en deux étapes : (1) créer une commande `enrich-tvdb-ids` pour peupler les tvdb_id manquants sur les 18 séries concernées, puis (2) exécuter `enrich-episode-titles` pour enrichir les titres via TVDB.

## Purpose
Sans titre d'épisode, les fiches web séries affichent "S01E01" sans contexte. L'utilisateur ne peut pas identifier l'épisode qu'il cherche. Le tvdb_id manquant bloque l'enrichissement de 105 épisodes (28% des 383).

## Output
- Commande `enrich-tvdb-ids` pour rechercher et peupler les tvdb_id des séries
- 18 séries sans tvdb_id traitées
- `enrich-episode-titles` exécuté pour enrichir les 383 épisodes sans titre
</objective>

  <action>
    Ajouter une commande `enrich-tvdb-ids` après `enrich-episode-titles` (après ligne 1234) :

    **Fonctionnement :**
    1. Charger toutes les séries sans tvdb_id : `SeriesModel.tvdb_id == None`
    2. Pour chaque série, rechercher sur TVDB via `tvdb_client.search(title, year)`
    3. Sélection du meilleur match :
       a. Match exact sur le titre (case-insensitive) avec même année → prise directe
       b. Si pas de match exact, utiliser le titre original (TMDB) si disponible
       c. Sinon, prendre le premier résultat si le titre est suffisamment proche (fuzzy ≥ 0.80)
    4. Affecter `series.tvdb_id = int(best_match.id)`
    5. Commit par série

    **Options CLI :**
    - `--dry-run` : afficher les matchs sans modifier la base
    - `--limit N` : limiter le nombre de séries traitées (0 = toutes)

    **Affichage Rich :**

    - Résumé : trouvées, non trouvées, erreurs
    - En dry-run, afficher chaque match potentiel avec le score
