    ```python
    def _normalize_title(title: str) -> str:
        """Normalise un titre pour comparaison : minuscules, sans accents, sans articles."""
        import unicodedata
        # Supprimer les accents
        nfkd = unicodedata.normalize("NFKD", title)
        ascii_str = "".join(c for c in nfkd if not unicodedata.combining(c))
        # Minuscules
        result = ascii_str.lower().strip()
        # Supprimer les articles en début (L', Le, La, Les, The, A, An, Un, Une, Des, Das, Der, Die, El, Los, Las)
        import re
        result = re.sub(r"^(l'|le |la |les |the |a |an |un |une |des |das |der |die |el |los |las )", "", result)
        return result
    ```

    **2. Modifier la Passe 1 (symlinks)** — Après l'échec du match exact (ligne 445 `if not results`), ajouter des passes successives :

    b) **Match par contenu** : Si le nom de fichier contient ` - ` (sous-titre), extraire la partie avant le tiret et chercher en base. Ex: "The Blind Side  -  L'éveil d'un champion" → chercher "The Blind Side".

    # Index par année → liste de (normalized_title, original_normalized, movie)
