<objective>
## Goal
Enrichir les films avec les données de collection TMDB (`belongs_to_collection`) et proposer une vue « Collections / Sagas » dans la bibliothèque web, permettant de regrouper visuellement les films appartenant à la même saga (Kill Bill, Harry Potter, Dune, etc.).

## Purpose
Actuellement, les films d'une même saga sont dispersés dans différents genres (Kill Bill Vol 1 en Thriller, Vol 2 en Action). L'utilisateur n'a aucun moyen de voir les films d'une saga regroupés. L'API TMDB fournit un champ `belongs_to_collection` avec l'ID et le nom de la collection. En exploitant cette donnée, on peut offrir un regroupement visuel par saga dans la bibliothèque web.

## Output
- Champs `collection_id` et `collection_name` dans MovieModel + entité Movie
- `get_details()` du TMDBClient enrichi pour extraire la collection
- Commande CLI `enrich-collections` pour peupler les 5675 films existants
- Page web « Collections » listant les sagas avec leurs films
- Badge collection sur les cartes films dans la bibliothèque
</objective>
