<objective>
## Goal
Ajouter un nouveau backend lecteur "DuneHD" capable d'envoyer un ordre de
lecture à un media player Dune HD via son API HTTP (`/cgi-bin/do?cmd=start_file_playback`),
avec mapping automatique `storage/Films/*` et `storage/Séries/*` vers URLs SMB.

## Purpose
Permet à l'utilisateur de déclencher la lecture d'un film ou épisode sur le
DuneHD du salon (ou toute autre machine Dune HD du réseau local) depuis
l'interface web CineOrg, au même titre que les profils mpv existants.

## Output
- Schéma profil étendu avec un champ `type` ("mpv" par défaut, "dunehd" nouveau)
  et des champs dunehd (`ip`, `smb_movies_prefix`, `smb_series_prefix`)
  rétrocompatibles avec les profils existants
- `DuneHDPlayer` dans `src/services/player/dunehd_player.py` — mapping
  chemin local → URL SMB + appel API + parsing XML
- Dispatcher `_launch_player()` étendu : route vers `DuneHDPlayer` quand
  `profile["type"] == "dunehd"`, sinon comportement mpv actuel
- Tests unitaires couvrant mapping films/séries, encodage URL, erreurs API
</objective>

```
  --data-urlencode "cmd=start_file_playback" \

```
Réponse XML : `command_status=ok`, `player_state=file_playback`, lecture lancée.

## Mapping SMB confirmé
- `storage/Films/<genre>/.../fichier.mkv` → `smb://<srv>/Films/<genre>/.../fichier.mkv`
- `storage/Séries/<letter>/.../fichier.mkv` → `smb://<srv>/Series TV/<letter>/.../fichier.mkv`
  (noter l'accent local "Séries" → share sans accent "Series TV")
- Les espaces doivent être URL-encodés `%20` dans `media_url`
