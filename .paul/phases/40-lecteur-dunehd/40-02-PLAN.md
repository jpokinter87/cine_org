<objective>
## Goal
Étendre l'interface web de configuration des profils lecteur pour supporter
la création/édition de profils DuneHD, avec champs conditionnels selon le
type choisi (mpv vs dunehd), validation côté serveur, et affichage adapté
dans les cartes profil.

## Purpose
Permet à l'utilisateur de configurer ses profils DuneHD entièrement via
l'interface web (IP du Dune, préfixes SMB films/séries), sans éditer
`player_profiles.json` à la main. Rend la fonctionnalité DuneHD utilisable
sans connaissance technique.

## Output
- Sélecteur "Type" (mpv / dunehd) dans les formulaires add/edit
- Champs conditionnels : SSH/path-prefix pour mpv, IP/SMB pour dunehd,
  masqués dynamiquement via JS selon le type choisi
- Validation backend : IP format pour dunehd, prefixes SMB non vides
- Badge de type sur les cartes profil existantes
- Tests des routes CRUD étendues
- Checkpoint visuel final : création + lecture end-to-end sur Dune réel
</objective>

## AC-1: Formulaire d'ajout étendu
```gherkin
Given l'utilisateur ouvre la section "Profils lecteur" dans /config
When il clique "Ajouter un profil"
Then le formulaire propose un select "Type" avec options "mpv" et "dunehd"
  And les champs affichés s'adaptent au type sélectionné :
    - type=mpv : programme, cible, ssh_host, ssh_user, local_path_prefix, remote_path_prefix
    - type=dunehd : ip, smb_movies_prefix, smb_series_prefix
  And le type par défaut est "mpv" (rétrocompatibilité visuelle)
```

## AC-2: Édition d'un profil DuneHD
```gherkin
Given un profil existant de type dunehd
When l'utilisateur clique "Modifier"
Then le formulaire pré-remplit ip, smb_movies_prefix, smb_series_prefix
  And les champs mpv sont masqués
  And un changement de type vers "mpv" révèle les champs mpv (et vice-versa)
```

## AC-3: Validation backend
```gherkin
Given un POST /config/player-profiles/add avec type=dunehd
When le champ ip est vide ou les prefix SMB sont vides
Then la route retourne un fragment HTML avec message d'erreur explicite
  And aucun profil n'est créé

Given un POST avec type=dunehd et des valeurs valides
When les champs mpv (ssh_host, ssh_user, etc.) sont vides
Then le profil est créé sans erreur (ces champs sont optionnels pour dunehd)
```

## AC-4: Affichage cartes profil
```gherkin
Given un profil de type dunehd
When la liste des profils est affichée
Then la carte montre un badge "DuneHD" visible
  And affiche l'IP et les prefix SMB (pas les champs ssh_* qui sont vides)

Given un profil de type mpv
When la liste est affichée
Then l'affichage actuel est préservé (badge "Local" ou "Remote SSH")
```

## AC-5: Test end-to-end manuel
```gherkin
Given l'utilisateur a créé un profil dunehd via le formulaire web
  (ip=192.168.1.4, smb_movies_prefix=smb://192.168.1.2/Films, smb_series_prefix=smb://192.168.1.2/Series TV)
When il clique "Visionner" sur un film depuis la bibliothèque web
  et sélectionne ce profil dans le popover
Then le DuneHD commence effectivement la lecture du film
  And l'interface web ne renvoie pas d'erreur
```
