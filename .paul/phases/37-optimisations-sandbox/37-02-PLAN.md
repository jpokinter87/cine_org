<objective>
## Goal
Créer un système de sandbox complet pour les fichiers orphelins : service de déplacement, interface web de gestion, actions de suppression définitive et réinjection dans le workflow.

## Purpose
Les orphelins (fichiers storage non ciblés par un symlink) encombrent le stockage sans être accessibles via le médiacenter. Le sandbox permet de les isoler pour revue avant décision (supprimer ou réintégrer).

## Output
- `SandboxService` pour déplacer/lister/restaurer/supprimer les orphelins
- Section sandbox dans la page maintenance avec interface de gestion complète
- Configuration `sandbox_dir` dans les settings
</objective>

## AC-1: Configuration sandbox
```gherkin
Given la configuration de l'application
When sandbox_dir n'est pas défini
Then le répertoire par défaut est {storage_dir}/../.sandbox

```

## AC-2: Déplacement orphelins vers sandbox
```gherkin
Given des fichiers orphelins détectés dans storage/
When l'utilisateur clique "Sandboxer les orphelins" sur /maintenance
Then les fichiers sont déplacés vers .sandbox/orphans/ en préservant l'arborescence relative à storage/
And le nombre de fichiers déplacés est affiché
```

## AC-3: Interface web sandbox
```gherkin
Given des fichiers dans .sandbox/orphans/
When l'utilisateur accède à la section sandbox sur /maintenance
Then la liste affiche : nom, taille, date modification, chemin original
And l'utilisateur peut cocher des fichiers pour suppression définitive
And l'utilisateur peut cocher des fichiers pour réinjection dans le workflow
And les actions sont restreintes à localhost
```

## AC-4: Suppression définitive depuis sandbox
```gherkin
Given des fichiers cochés dans le sandbox
When l'utilisateur clique "Supprimer définitivement"
Then les fichiers sont supprimés physiquement
And les répertoires vides sont nettoyés
And la liste se met à jour
```

## AC-5: Réinjection dans le workflow
```gherkin
Given des fichiers cochés dans le sandbox
When l'utilisateur clique "Réinjecter dans le workflow"
Then les fichiers sont déplacés vers le répertoire downloads (scan source)
And la liste se met à jour
And les fichiers seront traités au prochain scan workflow
```

  <name>Task 1: SandboxService et configuration</name>
  <files>src/config.py, src/services/sandbox_service.py, tests/unit/test_sandbox_service.py</files>
  <action>
    1. Dans config.py, ajouter `sandbox_dir: Path` aux Settings :
       - Défaut : `{storage_dir}/../.sandbox` (résolu via property ou validator)
       - Même pattern de validation que les autres paths (expand_path)

    2. Créer src/services/sandbox_service.py avec :
       - `SandboxService(sandbox_dir, storage_dir, downloads_dir)` — injection via container
       - `sandbox_orphans(orphan_paths: list[Path]) -> int` :
         - Déplace chaque fichier vers `sandbox_dir/orphans/{relative_path}` en préservant l'arborescence relative à storage_dir
         - Crée les sous-répertoires nécessaires
         - Retourne le nombre de fichiers déplacés
       - `list_sandboxed() -> list[SandboxedFile]` :
         - Parcourt sandbox_dir/orphans/ récursivement
         - Retourne nom, taille, date modification, chemin original (reconstitué depuis l'arborescence)
       - `delete_files(paths: list[Path]) -> int` :
         - Supprime physiquement les fichiers
         - Nettoie les répertoires vides remontant
         - Retourne le nombre supprimé
       - `reinject_files(paths: list[Path]) -> int` :
         - Déplace les fichiers vers downloads_dir
         - Retourne le nombre réinjecté
       - Dataclass `SandboxedFile(path, name, size, modified, original_path)`

    3. Enregistrer SandboxService dans container.py

    4. Tests unitaires avec tmp_path :
       - Test sandbox_orphans préserve l'arborescence
       - Test list_sandboxed retourne les bons fichiers avec métadonnées
       - Test delete_files supprime et nettoie les dossiers vides
       - Test reinject_files déplace vers downloads

    Éviter :
    - Ne PAS toucher à IntegrityChecker (détection orphelins existante)
    - Ne PAS ajouter de modèle DB pour le sandbox (fichiers uniquement)
