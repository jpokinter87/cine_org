<objective>
## Goal
Détecter et nettoyer les symlinks cross-genre : symlinks dans video/ qui pointent vers le même fichier physique mais sont classés dans des genres différents (ex: un film "Comédie dramatique" avec un symlink dans Comédie ET un dans Drame).

## Purpose
Élimine les doublons parasites dans la vidéothèque qui faussent le comptage et encombrent la navigation. Un film ne doit avoir qu'un seul symlink, dans son genre prioritaire selon GENRE_HIERARCHY.

## Output
- Nouvelle analyse `scan_cross_genre_duplicates` dans le pipeline cleanup
- Nouveau correcteur `fix_cross_genre_duplicates` qui supprime les symlinks redondants
- Intégration dans la page maintenance web (analyse + fix)
- Intégration dans la commande CLI cleanup
- Tests unitaires
</objective>
