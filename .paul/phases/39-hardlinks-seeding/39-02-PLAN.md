<objective>
## Goal
Service de purge des hardlinks expirés avec commande CLI et timer systemd quotidien.

## Purpose
Les hardlinks créés par le plan 39-01 ont une durée de vie limitée. Ce plan ajoute le mécanisme de rotation : purger les hardlinks dont la date d'expiration est passée, nettoyer les dossiers vides, et automatiser via un timer systemd quotidien.

## Output
- HardlinkService avec purge_expired(), list_active(), get_stats()
- Commande CLI `cineorg purge-hardlinks` (--dry-run, --force)
- Timer systemd `cineorg-purge.timer` pour exécution quotidienne
</objective>

    class HardlinkService:
        def __init__(self, settings: Settings):
            self._settings = settings

        def purge_expired(self, force_all: bool = False, dry_run: bool = False) -> PurgeResult:
            """Supprime les hardlinks expirés (ou tous si force_all).
            - SELECT WHERE expires_at < utcnow() (ou SELECT ALL si force_all)
            - Pour chaque : os.unlink(download_path) si le fichier existe
            - Remonter les dossiers parents vides jusqu'à downloads_dir
            - DELETE les entrées DB
            - Retourner PurgeResult(purged=N, errors=[], freed_paths=[])
            """

        def list_active(self) -> list[HardlinkInfo]:
            """Liste les hardlinks non expirés avec infos (path, taille, jours restants)."""

        def get_stats(self) -> HardlinkStats:
            """Statistiques : total actifs, total expirés, taille référencée."""

    Dataclasses PurgeResult, HardlinkInfo, HardlinkStats dans le même fichier.

    Nettoyage dossiers : après unlink, remonter via path.parent jusqu'à
    downloads_dir, supprimer les dossiers vides avec rmdir() (échoue silencieusement
    si non vide).

    Dans container.py : ajouter provider Factory HardlinkService(settings=config).
