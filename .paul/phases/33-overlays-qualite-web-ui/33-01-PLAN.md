<objective>
## Goal
Ajouter des badges qualite visuels (resolution, codec video, langue) sur les posters de la grille bibliotheque pour permettre un apercu technique sans ouvrir la fiche.

## Purpose
Les donnees techniques sont deja en base et visibles sur les fiches detail, mais invisibles dans la grille de navigation. Des overlays compacts sur les posters permettent de reperer instantanement la qualite d'un fichier lors du parcours de la bibliotheque.

## Output
- Badges overlays sur les posters dans `_grid.html`
- Styles CSS compacts pour les badges qualite sur les cartes
- Donnees langue ajoutees aux items de la grille
</objective>

<acceptance_criteria>

## AC-1: Badges resolution visibles sur les posters films
```gherkin
Given un film avec une resolution en base (ex: "1920x1080")
When la grille bibliotheque s'affiche
Then un badge compact "1080p" apparait en bas a gauche du poster
And le badge utilise un code couleur selon la resolution (4K > 1080p > 720p > SD)
```

## AC-2: Badge codec video visible sur les posters films
```gherkin
Given un film avec un codec video en base (ex: "HEVC")
When la grille bibliotheque s'affiche
Then un badge compact avec le nom du codec apparait a cote du badge resolution
```

## AC-3: Badge langue visible sur les posters films
```gherkin
Given un film avec des langues en base (ex: ["fr", "en"])
When la grille bibliotheque s'affiche
Then un badge compact "Multi" ou "FR" ou "VO" apparait
And "Multi" si plusieurs langues, sinon la langue principale en majuscule
```

## AC-4: Pas de badges techniques sur les series
```gherkin
Given une serie dans la grille (pas de donnees techniques au niveau serie)
When la grille bibliotheque s'affiche
Then aucun badge technique n'apparait sur le poster de la serie
```

## AC-5: Badges harmonieux avec les badges existants
```gherkin
Given un poster avec badge type (Film/Serie), badge note, et nouveaux badges qualite
When tous les badges sont affiches
Then les badges qualite sont en bas a gauche du poster (zone separee des badges existants en haut)
And les badges ne masquent pas le poster de maniere excessive
And le design reste coherent avec la charte graphique sombre du projet
```
