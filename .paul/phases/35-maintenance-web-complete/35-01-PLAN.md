<objective>
## Goal
Ajouter l'execution des corrections cleanup et integrite directement depuis l'interface web de maintenance, avec progression SSE et resultats detailles fichier par fichier.

## Purpose
Actuellement la page maintenance est en lecture seule : elle affiche les diagnostics mais renvoie vers le CLI pour corriger. L'utilisateur doit quitter le navigateur, lancer des commandes CLI, puis revenir verifier. Ce plan supprime ce friction en ajoutant des boutons "Corriger" qui executent les memes operations que `cineorg cleanup --fix` depuis le web.

## Output
- Boutons "Corriger" sur chaque categorie de problemes cleanup (symlinks casses, mal places, doublons, repertoires surdimensionnes, vides)
- Endpoint SSE d'execution avec progression phase par phase
- Template de resultats detailles montrant chaque action effectuee (fichier repare, deplace, supprime, etc.)
- Bouton "Corriger" sur les symlinks casses de l'integrite (repair-links auto)
- Restriction localhost pour toutes les actions correctives (coherent avec la suppression bibliotheque)
</objective>
