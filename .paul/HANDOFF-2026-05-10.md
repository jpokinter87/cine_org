## Décisions techniques de cette session

- **Sentinel `_UNSET = object()`** dans les helpers de tests : distingue
  "non fourni" (default) de "explicitement None" (pour tests broken/
  no-target candidates).
- **`item_id` = `xxh3_64(str(symlink_path))`** : empreinte stable pour
  reprise sans collision sur dataset réaliste.
- **state_store sqlite3 stdlib** : choix volontaire de ne PAS passer par
  SQLModel — c'est un fichier opérationnel séparé de la DB CineOrg.
- **Threshold inclusif** : `value >= threshold` → MIGRATE. Une note de
  6.0 avec seuil 6.0 passe.
- **`RsyncRunner` Protocol** : injectable, par défaut `subprocess`. Permet
  un FakeRsync en test qui copie réellement le fichier dans `on_success`
  pour tester les vrais hashes.
- **Swap symlink atomique** : `os.symlink(new_target, tmp)` puis
  `os.replace(tmp, symlink_path)`. Atomique tant qu'on est sur le même
  filesystem ; sinon le `os.replace` ne sera pas atomique mais ne se
  produit pas dans CineOrg (les symlinks sont sur le même NAS que les
  fichiers organisés).
- **Reprise via détection destination match** : si la destination existe
  déjà avec le bon hash xxh3_64, on saute rsync et on finalize directement.
  Couvre les crashes mid-flight où le state store n'a pas pu écrire.
- **Helpers `build_plan` / `run_apply` / `run_status`** séparés des
  commandes Typer pour testabilité (Typer = surface mince).
- **`IMDbDatasetImporter(cache_dir=Path, session=Session)`** : la
  signature requiert un `cache_dir`, pas juste une session. Default
  `Path(".cache/imdb")` dans `build_plan`.
- **Docstring scanner.py "Séries" littéral** : interdit par
  `TestRemainingSeriesRefs` (gardien sur la migration Séries→Series).
  Reformulé en "Series, Animations".
