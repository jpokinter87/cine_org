## Phase 39: Hardlinks Seeding

## Key Decisions (v2.0)

- Phase 32 NFO abandonnée : Jellyfin scrape TMDB tout seul, sidecar NFO/poster/fanart multipliaient les fichiers pour un bénéfice marginal
- Hardlinks seeding post-transfert : `os.link(storage, download)` recrée le fichier original pour le tracker BitTorrent
- `st_nlink > 1` comme filtre scanner : ignore les hardlinks lors du scan downloads, simple et sans requête DB
- Purge hardlinks timer systemd : `cineorg-purge.timer` quotidien avec `Persistent=true` et `RandomizedDelaySec`
- Service systemd direct (pas de nginx) : usage personnel réseau local, uvicorn suffit
- Sandbox complète avec garde-fou `_is_subdivision_path()` : empêche de détruire une subdivision entière
